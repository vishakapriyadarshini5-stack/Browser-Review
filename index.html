Browser Reviews

Browsers, reviewed honestly.

Honest reviews from someone who actually uses them.

Light on RAM

Z

Zen

A sidebar-style browser built on Firefox.

My review My favorite alternative to all the other browsers. It's like Arc but lighter, since it runs on Firefox. The only downside is that it's in beta, so it constantly has some bugs and errors.
B

Brave

A Chrome-based browser with a built-in ad blocker.

My review Lighter in many cases, but it sometimes has its own advertising.

Everyday browsing

O

Opera One

The default Opera browser.

My review The default Opera, but it takes as much RAM as the two special Opera versions. Best for normal usage, though.
O

Opera Air

Opera's calm, relaxed browser.

My review Averages around 1.2 GB of RAM, but it feels light compared to how satisfying the app is to use.
A

Arc

The browser that started the sidebar layout.

My review Arc is the original of this layout, but it's heavier than Zen.

Gaming

G

Opera GX

The gaming version of Opera.

My review It's fine but not the best. It has a RAM limiter of up to 1.5 GB.

Heavy on RAM

F

Firefox

The independent browser from Mozilla.

My review Firefox seems light but isn't. It's heavy, at around 1000 MB.
C

Google's browser.

My review A RAM eater. It takes up so much RAM that even the internet hates it.
